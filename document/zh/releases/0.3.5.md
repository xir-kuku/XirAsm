# XIRASM 0.3.5

本版本扩充 Android SDK，并为 Meta/DSL 结构体和联合体增加原生浮点字段。
内含后端库 0.1.5。

- `os/android/sdk.inc` 提供 SDK 声明，不额外引入动态库。SDK 包含 25 种公开
  NDK 结构布局及其明确的 ARM32 变体，支持嵌套结构、固定数组、联合体和回调字段。
- 结构体和联合体字段支持 `f32` 与 `f64`，可使用自然对齐或紧凑布局、带类型的
  默认值及 IEEE-754 字节输出。显式转换沿用现有标量转换规则。
- Android 目录覆盖 25 个库、4,405 个公开名称，以及五种 ABI 的 22,956 条准确
  提供者记录。查询保留库归属、最低 API 级别、符号类型及 GNU 符号版本。
- 受检查的 Android 导入验证目标镜像 ABI、最低 SDK 级别、库及符号类型。
  对象导入使用 GOT 槽并保持 OBJECT 动态符号类型。原有 helper 也会拒绝其他库的符号。
- Android 教程和原生示例改用结构体类型及受检查的导入。发行包包含完整 SDK、
  格式宏包和用户文档。
