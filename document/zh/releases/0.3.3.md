# XIRASM 0.3.3

Meta 与 DSL 求值不再重复做已经做过的事，AArch64 源码的汇编速度因此快了约一倍。产出的字节没有任何变化。

## 条件解析结果改为保留，不再反复解析

`meta_if` 的条件过去每次执行都要从文本重新解析一遍，解析完再释放。在每条指令跑一次的循环里，解析的代价超过了求值它所得出的那个条件本身。

现在按条件缓存解析结果并复用：一条语句无论执行多少次，它只解析一次。在这个阶段条件与上下文无关，所以同一份解析结果在不同作用域下依然正确；文本是拷进来的，因此调用方可以传生命周期更短的切片。

## 捕获的绑定改为借用，不再重复拷贝

`operand.eval` 过去每次调用都会把随操作数一起捕获的全部绑定克隆一遍来重建作用域。捕获本身已经持有一份"捕获时"的副本，所以第二份是多余的：每求值一个操作数，就把那些生成的表整个走了一遍——其中一张表有 549 个寄存器。

现在这些绑定改为向捕获借用，而不是拷贝。捕获的含义没有变，仍然是"捕获时看到的值"，不受之后模块改动的影响。借用的绑定声明为 `const`，而所有可能写入绑定的路径都拒绝不是 `let` 的绑定，因此无法通过这些绑定改到被借用的存储。

## 效果

在 10 万条指令的 AArch64 夹具上，降级阶段从约 100 秒降到约 43 秒；而对应的 x86-64 夹具仍然快约 385 倍，因为它根本不经过 DSL 这一层。全部夹具（含教程与可执行格式输出）汇编出的字节完全一致。
