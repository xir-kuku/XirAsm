# XIRASM 0.3.4

本版本修复 SPIR-V 文本编码，强化 Meta/DSL 与输出状态的边界，并更新生成的
AArch64 指令库。内含后端库 0.1.5。

- SPIR-V 表更新至当前 1.6 语法：877 个核心指令条目、58 个别名，以及 18 组扩展
  指令集。依赖上下文的操作数、枚举参数与各指令集专属的语法均保留其定义。
- SPIR-V 标量编码保留十六进制浮点载荷，正确编码半精度与 BFloat16 常量，并处理
  64 位 `OpSwitch` 字面量。非法 `OpSpecConstantOp` 操作与不支持的浮点编码会报告错误。
- SPIR-V 符号 ID 与前端常量保持独立。字符串中的 `here()`、`label_addr(...)`
  等文本不再被当作前端调用展开。
- 返回值 Meta/DSL 函数不能修改调用者的可变绑定或容器。空数据写入保持尾部预留
  空间的裁剪行为，已关闭的输出区域拒绝继续写入。
- AArch64 指令库更新生成清单，编码逻辑相同的指令形式共用编码体。
