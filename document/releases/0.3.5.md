# XIRASM 0.3.5

This release expands the Android SDK and adds native floating-point fields to
Meta/DSL structures and unions. It includes backend library 0.1.5.

- `os/android/sdk.inc` provides SDK declarations without adding dynamic imports.
  The SDK includes 25 public NDK structure layouts with explicit ARM32 variants,
  including nested structures, fixed-size arrays, unions, and callback fields.
- Structure and union fields support `f32` and `f64`, with natural or packed
  alignment, typed defaults, and IEEE-754 byte emission. Explicit conversions
  preserve the existing scalar conversion rules.
- The Android catalog covers 25 libraries and 4,405 public names, with 22,956
  exact provider records across five ABIs. Queries preserve library ownership,
  minimum API levels, symbol kinds, and GNU symbol versions.
- Checked Android imports validate the selected image ABI, minimum SDK level,
  library, and symbol kind. Object imports use GOT slots and retain OBJECT
  dynamic-symbol types. Existing helpers also reject symbols from other libraries.
- Android tutorials and native demo sources use the structure types and checked
  imports. The distribution includes the complete SDK, format helpers, and user
  documentation.
