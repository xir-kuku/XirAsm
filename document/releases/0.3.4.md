# XIRASM 0.3.4

This release corrects SPIR-V text encoding, strengthens Meta/DSL and output
state boundaries, and updates the generated AArch64 instruction library.
It includes backend library 0.1.5.

- SPIR-V tables follow the current 1.6 grammar: 877 core instruction entries,
  58 aliases, and 18 extended instruction sets. Context-dependent operands,
  enum parameters, and instruction-set-specific schemas retain their grammar.
- SPIR-V scalar encoding preserves hexadecimal floating-point payloads,
  encodes half and BFloat16 constants correctly, and handles 64-bit `OpSwitch`
  literals. Invalid `OpSpecConstantOp` operations and unsupported floating-point
  encodings produce diagnostics.
- SPIR-V symbolic IDs remain distinct from frontend constants. Quoted strings
  containing names such as `here()` or `label_addr(...)` retain their text.
- Value-returning Meta/DSL functions cannot modify caller-owned mutable bindings
  or containers. Empty data writes preserve reserve-tail trimming, and closed
  output regions reject further writes.
- The AArch64 library uses an updated generated inventory and shared encoding
  bodies for instruction forms with the same encoding logic.
